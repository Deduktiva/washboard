Notes

  1. Requests list (NSOutlineView, source-list style). Dot = unsaved buffer, ⚠ = last validation failed. Return renames inline; ⌘D duplicates; ⌘⌫ deletes.
  2. Server popup. Defaults to this request's last-used server; changing it is stored immediately.
  3. Send (⌘↩) validates first and refuses to send on errors. There is no Validate button: requests are validated as they are edited, and Project ▸ Validate (⌘B) skips the wait.
  4. HTTP Log (⌥⌘L). Save All (⌘S) is menu-only; autosave runs 1 s after typing stops.
  5. Live well-formedness state. Broken XML turns this red and underlines the position. Try the CreateOrder 1 request.
  6. Operations from the WSDL, grouped service › port. Double-click creates a request named <Operation> <n> from the generated template.
  7. Response beside the request, in one vertical split. Its status line shares a band with the request bar; tabs Response and Headers.
  8. History drawer under the response, kept on disk (last 20). Collapsed it is one line with a dot per exchange (red: fault or failure; ringed: shown). Click it, then pick a row.
  9. An older exchange shows its request as sent, read-only, and this strip under the toolbar replaces the toolbar items, so it cannot be sent. Show Latest (Esc) returns to the editor; Restore Request copies the sent request into it.

Notes

  1. Sheet on the welcome window or File ▸ New Project… (⇧⌘N). The project folder is Location / Name.
  2. The reference check runs as soon as the WSDL is picked and again when XSDs are added. Remote schemaLocation URLs are matched by file name only.
  3. Create stays disabled while any reference is unresolved or the schema set fails to compile.
  4. Project ▸ Replace WSDL… reuses this sheet and ends with a report of added/removed operations and requests that no longer validate.
